# LAST DEFENSE — FINAL LINE v0.14

## 실행
1. ZIP 압축을 풀고 VS Code에서 파일 > 폴더 열기로 LAST-DEFENSE-VSCode 폴더를 선택합니다.
2. index.html을 브라우저에서 직접 열거나 Live Server 확장 설치 후 index.html 우클릭 > Open with Live Server를 선택합니다.
3. 난이도 선택 후 작전 시작을 누릅니다. 브라우저 오디오 정책에 따라 첫 클릭 이후 소리가 재생됩니다.

## 구조
- index.html: 화면 구성
- style.css: UI 및 디자인
- game.js: 게임 로직, 밸런스, 오디오
- assets/: 캐릭터 이미지

## GitHub
VS Code 소스 제어에서 저장소 초기화 > 변경사항 커밋 > Publish to GitHub를 선택합니다. Git 설치 및 GitHub 로그인이 필요합니다.

기존 v0.14의 게임 로직과 리소스를 그대로 분리했습니다.
